# bassem-krayem.dev

Personal website of **Bassem Krayem**, junior backend software engineer.
Live at https://bassem-krayem.dev

## Stack

- Node.js + Express 5, server-side rendered with EJS
- Plain CSS, mobile-first, built with accessibility in mind (skip link, focus styles, screen-reader hints)
- Deployed on Heroku

## Pages

| Route | Content |
|---|---|
| `/` | Introduction, status, highlights |
| `/about` | My full story |
| `/portfolio` | Projects and open-source contributions |
| `/contact` | Contact channels |
| `/resume` | CV (PDF, shown in the browser) |
| `/robots.txt`, `/sitemap.xml` | For search engines |

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
```
